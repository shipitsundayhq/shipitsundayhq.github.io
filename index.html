ShipIt Sunday is a free weekly vibe-coding challenge. Each Friday you get one small app or game idea, a starter template and a prompt. Build it with any AI coding tool and ship it by Sunday night.

How it works

  1. 1 · Friday: drop

    A theme, rules, starter template and a copy-paste prompt land at 9am PT.

  2. 2 · Weekend: build

    Use Cursor, Claude Code, Bolt, Lovable, v0, Replit or whatever you like. Aim for 2–4 hours.

  3. 3 · Sunday: ship

    Submit a live, no-login link by 11:59pm PT through GitHub or X with #ShipItSunday.

  4. 4 · Monday: showcase

    Every valid entry gets featured, plus awards like Most Fun and Most Cursed.

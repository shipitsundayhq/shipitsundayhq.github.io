Challenge #1 · Fri Oct 16 – Sun Oct 18, 2026 (PT)

One-Button Game

Build a complete browser game controlled by one input only: a single key (Space), a click or a tap. The challenge is to make one button feel fun.

Example entry: Pulse Hop

Your orb circles a ring. Press when it lines up with the spinning gap to hop outward. Hit near the center of the gap for a PERFECT.

Play full screen →

Rules

  1. Build it this weekend: Friday drop to Sunday 11:59pm PT. No pre-existing projects.
  2. Build it mostly with AI (any tool). Libraries are fine.
  3. One input only: Space, click or tap.
  4. Must run in the browser, be free, need no login or download, and load fast.
  5. Must work on a phone (a tap counts as the button).
  6. Only use your own assets. No ripped art, music or characters.
  7. One entry per person; teams of 2 are OK.

Starter template

A single index.html with a canvas, game loop, Space/click/tap input, score and restart. No build step. Template repo on GitHub (coming soon).

Starter prompt

Using the attached index.html as a base, build a complete one-button browser game. The ONLY input is Space / mouse click / screen tap. Game idea: [your idea in one sentence]. Requirements: title screen "Press to start", a core loop that gets harder over time, score plus best score saved in localStorage, a game-over screen with "Press to retry", juicy feedback (screen shake, particles, Web Audio sound effects with no external files), and 60fps on a phone. Keep everything in one file. Then list 3 ways to make it more fun and implement the best one.

Need an idea? A frog that can only jump on the beat · hold to charge, release to launch · tap to flip gravity.

Stretch goal

Add one twist that uses the same button differently, such as hold vs. tap, double-tap, or a meaning that changes each level. Bonus: a shareable "I scored X" link.
